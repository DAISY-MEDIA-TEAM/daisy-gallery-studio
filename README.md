# DAISY Post Studio

Static web app that makes Facebook posters for DAISY Lab (Data and Intelligent Systems Lab, PTIT): accepted papers, new members, seminars, recruitment and awards.

## Run locally
```bash
python3 -m http.server 8000
```
Open http://localhost:8000 (not via `file://`).

## Deploy on Vercel
Import this repo, Framework Preset **Other**, empty Build Command, Output Directory `.`.

See `CLAUDE.md` for details.
